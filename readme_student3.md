String Manipulation Toolkit

Files:
- transform.py : Contains functions to:
  - Convert text to uppercase
  - Convert text to lowercase
  - Merge two strings with an optional separator
  - Validate input types and raise clear errors for non-string values

- main.py : Imports functions from transform.py and demonstrates interactive usage with basic cancellation handling.

Functions:
- `to_uppercase(text)` -> uppercase string
- `to_lowercase(text)` -> lowercase string
- `merge_strings(str1, str2, separator="")` -> combined string

Run:
python main.py
