## Experiment Objective

To learn and practice:

- Git repository creation
- GitHub repository management
- Markdown documentation
- Version control using Git

---

## Commands Used

```bash
# Initialize Git repository
git init

# Check repository status
git status

# Stage files
git add .

# Commit changes
git commit -m "Updated README"

# Push to GitHub
git push origin main
```

## Learning Outcomes

After completing this experiment, we learned:

- Creating a local Git repository
- Connecting a project with GitHub
- Tracking changes using Git
- Creating commits with meaningful messages
- Writing project documentation using Markdown
- Updating and maintaining a README file
